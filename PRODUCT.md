# Amplifi

## Product
A Windows-first desktop image upscaler based on Upscayl. Users enhance images locally with selectable models and compare results. Preserve Upscayl feature parity before adding model recommendations.

## Stack
Tauri with Rust application logic, a web interface, and the existing NCNN/Vulkan native engine.

## Constraints
No GitHub push until explicitly requested. Respect upstream and model licenses. macOS and Linux portability is a goal after Windows.
